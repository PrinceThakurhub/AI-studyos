# AI StudyOS — backend (Module 1)
Setup: `python -m venv .venv && source .venv/bin/activate` (Windows: `.venv\Scripts\activate`)
`pip install -r backend/requirements.txt` → `copy .env.example .env` and add your ANTHROPIC_API_KEY
Run: `cd backend && uvicorn main:app --reload` → API docs at http://localhost:8000/docs
